# Título del Proyecto

Gestor de Notas

## Descripción
El **Gestor de Notas** es una aplicación de prueba, diseñada para organizar y administrar notas de manera eficiente. Solo es una versión de prueba orientada a la modificación y prueba de código.

## Funcionalidades
- **Mostra Menú:** Muestra el menú de opciones.
- **Añadir Notas:** Permite guardar notas.
- **Visualizar Notas:** Lista todas las notas guardadas en el sistema.
- **Editar Notas:** Modifica el contenido de una nota existente.
- **Vaciar notas:** Borra las notas que ya no son necesarias.
